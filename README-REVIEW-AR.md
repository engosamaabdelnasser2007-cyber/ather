# أثر — حزمة مراجعة الخطوات 1 إلى 4

- `athar-preflight-readonly.sql`: فحص قراءة فقط للأعمدة والسياسات والقيود والفهارس والمشغلات.
- `AUDIT-REPORT-AR.md`: نتائج المراجعة وحدود الاختبارات.
- `prayer-times-sync.ts`: مسودة مزامنة محسّنة؛ تحتاج مطابقة المخطط واختبارًا على staging.
- `supabase_prayer_time_guard.sql`: لم يتم تغييره في هذه الجولة لأن سياسات RLS والمخطط الفعلي لم يتم التحقق منهما بعد.

## قبل النشر
1. شغّل استعلام الفحص للقراءة فقط.
2. راجع السياسات والمخطط.
3. اختبر المسودة على مشروع Supabase تجريبي.
4. اختبر حسابين منفصلين وحالات الصلاة والتواريخ والمناطق الزمنية.
5. لا تضع مفتاح service role في الواجهة أو في مستودع GitHub.
