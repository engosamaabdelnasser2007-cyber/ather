# أثر — نسخة بناء نظيفة

منصة عربية RTL لمتابعة العادات التعبدية. هذا الفرع يبدأ واجهة React + TypeScript + Vite منظمة بدل ملف HTML المجمّع القديم.

## الحالة الحالية
- واجهة responsive أولية مع الوضع الداكن والفاتح.
- نافذة تسجيل الدخول/إنشاء الحساب تستخدم Supabase Auth عند إعداد الاتصال.
- مخطط أولي لملف المستخدم وسجلات الصلاة والقرآن والأذكار مع RLS لكل مستخدم.
- لا تُعرض بيانات تجريبية على أنها محفوظة في السحابة؛ علامات الصلاة الحالية في الواجهة مؤقتة داخل الذاكرة فقط.
- لم يُنشر هذا الفرع ولم تُنفذ migration على قاعدة بيانات حقيقية.

## الإعداد
1. أنشئ مشروع Supabase مخصصًا لأثر أو تأكد أنه مشروع فارغ ومخصص لهذا التطبيق.
2. افتح SQL Editor، وراجع ثم نفّذ `supabase/migrations/202610090001_initial_schema.sql` على المشروع المقصود فقط.
3. انسخ `.env.example` إلى `.env.local` وضع URL ومفتاح publishable/anon الخاصين بالمشروع. لا تضع service-role key في الواجهة أو GitHub.
4. ثبّت الحزم باستخدام `npm install` ثم شغّل `npm run dev`.
5. في Vercel، أضف نفس متغيرات `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` ثم انشر فرع البناء للاختبار قبل استبدال الإنتاج.

## تنبيه أمني
- راجع سياسات RLS والمخطط في staging قبل أي استخدام إنتاجي.
- لا تستخدم مشروعًا يحتوي بيانات أخرى دون نسخة احتياطية ومراجعة دقيقة.
- مزامنة المواقيت والحارس الخادمي والتحقق من الصلاة حسب وقتها لم تُنفذ في هذه المرحلة.
- قسم القرآن والأذكار والرحلة ما زال واجهات أولية، ولا يحفظ سجلات حتى الآن.
